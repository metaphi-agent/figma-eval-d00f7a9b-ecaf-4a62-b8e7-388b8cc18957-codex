# Visual analysis – Dashboard Login

## Layout
- Full-screen login page (`1280×720`) with a solid blue background.
- Decorative background: 3 partially off-canvas circles on the left + a large blob shape on the right.
- Centered form column (`300px` wide) containing:
  - Cart icon
  - Username field
  - Password field
  - Primary "LOGIN" button
  - "Forgot password?" link aligned to the right of the form

## Spacing (from Figma node positions)
- Field-to-field vertical gap: 20px
- Second field to button gap: ~43px
- Button to link gap: ~11px

## Typography
- Font family: `Montserrat`
- Username/Password placeholders: `14px`, `Light (300)`, uppercase, white
- Forgot password: `16px`, `Medium (500)`, white
- Button label: `16px`, `SemiBold (600)`, uppercase, blue text

## Colors
- Base background: `#2148C0`
- Blob overlay: `#264ECA`
- Decorative circles: `#244BC5`, `#274FC7`, `#264ECA`
- Foreground: `#FFFFFF`

## Components
- Text inputs (transparent background, 1px white border, radius 4, height 45)
- Primary button (white fill, radius 4, drop shadow `0 4px 4px rgba(0,0,0,0.3)`)
- Text link (white, hover underline)
